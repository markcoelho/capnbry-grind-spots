# WoW Grind Spots

A static archive of the classic World of Warcraft (vanilla, levels 1–60) grinding-spot table originally hosted at
[capnbry.net/wow/gspots.php](http://capnbry.net/wow/gspots.php) by CapnBry.

The original page was generated by PHP; that server-side source isn't public. This repo preserves the **rendered HTML output** as `index.html`.

## Credits

- Original page: CapnBry (capnbry.net)
- Entries were contributed by forum posters (Zeeg, Voodoo, Kunst, Haunted, Sugardaddy, ExZippo, CapnBry and others), as linked in the "Source" column.
- Inspired by the Something Awful thread *"Guide to Sinister Strike: How I Learned to Stop Questing and Love the Grind"*.

## Viewing

Open `index.html` in a browser, or enable GitHub Pages on this repo (Settings → Pages → deploy from the `main` branch) to host it.
